# Install Stremio Origin on an Android phone or tablet

Download one file and open it. About two minutes.

**You need:** an Android phone or tablet (Android 7.0 or later) and the APK from this repository's Releases page: `stremio-origin-phone-1.1.0-arm64-v8a.apk` for nearly every phone from 2017 on, or `armeabi-v7a` for older 32-bit ones.

## Steps
1. **Download the APK** from Releases in the phone's browser.
2. **Open it** from the notification or the Downloads app.
3. **Allow installs from unknown apps** when Android asks: switch on the browser or file app you opened it with, and go back.
4. **Install**, then **Open** and sign in with your Stremio account.

## Good to know
- **Updating:** update in the app.
- **Casting:** to play on a TV, install Stremio Origin on the TV too, on the same network.
